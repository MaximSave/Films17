# Films17 — практические упражнения по JavaScript

Небольшой учебный проект с примерами и заданиями по основам JavaScript. В репозитории собраны независимые скрипты: от условий, циклов и функций до работы с DOM, событиями, объектами, массивами и асинхронным кодом.

## Что внутри

- интерактивная мини-база просмотренных фильмов (`Задание1.1.js`);
- условия, `switch`, циклы и управляющие операторы;
- функции, callback-функции и `setTimeout`;
- методы строк и чисел;
- массивы, сортировка, `spread` и копирование объектов;
- прототипы и основы ООП;
- поиск и изменение DOM-элементов, создание разметки и обработчики событий;
- простая демонстрационная страница со стилями.

## Структура

```text
.
├── index.html                         # Демонстрационная HTML-страница
├── style.css                          # Стили элементов на странице
├── Динамическая типизация.js          # Работа с DOM
├── События и их обработчики.js        # Обработчик клика
├── Задание1.1.js                      # Мини-база фильмов
├── Задание1.2.js / Задание1.3.js      # Условия и циклы
├── Задание1.5.js                      # Объекты и деструктуризация
├── Функции1.0.js                      # Функции
├── Массивы и псевдомассивы.js         # Массивы
├── Методы.js                          # Методы строк и чисел
├── ОПП.js                             # Прототипы
├── Передача по ссылке и по значению.js
└── index4.js                          # Callback и асинхронность
```

## Запуск

Проект не требует установки зависимостей или сборки.

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/MaximSave/Films17.git
   cd Films17
   ```

2. Откройте `index.html` в браузере.

На странице подключён скрипт `Динамическая типизация.js`: он меняет стили элементов и добавляет новую разметку. Остальные файлы — отдельные учебные примеры. Для запуска примеров без DOM удобно подключить нужный файл в конец `index.html` или выполнить его через консоль разработчика браузера.
